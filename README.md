## Learning Roadmap

| Phase | Duration | Focus | Key Topics |
| :---: | :---: | --- | --- |
| **1** | 2 weeks | HTML & CSS | Semantic and accessible HTML, forms, SEO basics, box model, positioning, Flexbox, Grid, responsive design, animations, CSS variables, z-index and stacking context |
| **2** | 1 week | Bootstrap | Grid system, utilities, navbar, cards, forms and validation, modals, offcanvas, carousel, accordion, toasts, customization |
| **3** | 2 days | Git & GitHub | Repositories, commits, branches, merges, conflict resolution, pull requests, issues, README documentation |
| **4** | 2 weeks | JavaScript | DOM, array functions, classes, asynchronous JS, `fetch`, HTTP methods, error handling, AbortController, XSS basics, input validation |
| **5** | 3 weeks | Frontend Framework | **React or Angular**: components, state, hooks or data binding, routing, forms, API integration |
| **6** | 2 weeks | Node.js | Express, REST APIs, MongoDB and SQL, CRUD, JWT authentication, middleware, security basics, file uploads, WebSockets |
| **7** | 3 weeks | Advanced Backend | **Python/FastAPI or C#/.NET**: API design, dependency injection, ORM, migrations, authentication, authorization |
| **8** | 2 days | Docker | Dockerfiles, building and running containers, containerizing a Node.js or Python app |
| **9** | 2 weeks | Final Project | Team-built BSS Restaurant App with API and web versions (V1 and V2) |

## Phase Tasks and Assessments

### Phase 1: HTML & CSS

| Task | Title | Duration | Description |
| :---: | --- | :---: | --- |
| 1.1 | Geometric Precision | 20 min | Build the Bangladesh flag using only CSS positioning (10:6 ratio, centered red circle) |
| 1.2 | CSS Grid Mastery | 40 min | Build a "Bento Box" style image gallery with six images |
| 1.3 | Structural Logic | 1 hour | Build an analog clock face with hour, minute, and second hands |
| 2.1 | Figma Conversion: Convention Center | 2 days | Full-page landing page with sticky navigation, hero, package cards, and footer |
| 2.2 | Figma Conversion: Restaurant System | 2 days | Landing page with bold typography, hero layout, and sticky navigation |
| 2.3 | Figma Conversion: Furniture E-Commerce | 2 days | Home page with product grid, hover overlays, newsletter, and footer |

**Assessment:** Static website project (personal portfolio), all course-related projects, and Figma conversions.

### Phase 2: Bootstrap

- Convert Frame 4 and Frame 6 of the Doctor House / E-commerce Figma file into a polished, responsive page.
- Use Bootstrap classes only, and customize Bootstrap where the design requires it.

**Assessment:** All course-related projects and Figma conversion.

### Phase 3: Git & GitHub

- Push the previous portfolio project to GitHub.
- Practice team collaboration using branches and pull requests.

### Phase 4: JavaScript

| Task | Description |
| :---: | --- |
| 1 | Loader |
| 2 | Practice with a third-party API (JSONPlaceholder) |

### Phase 5: Frontend Framework

### Phase 7: Advanced Backend

- Compare Node.js with FastAPI or .NET.

**Assessment:** Task Manager API project.

### Phase 8: Docker

- Dockerize a simple Node.js or Python application.

**Assessment:** A Docker container running the application.

## Development Workflow

1. Keep each exercise or project in the folder for its phase.
2. Commit regularly with clear, descriptive commit messages.
3. Use branches and pull requests during collaboration, and address feedback before merging.
4. Record weekly progress, reflections, and blockers in `weekly-logbook/`.
5. Document each project's purpose, prerequisites, setup, and run instructions in its README.
6. Exclude credentials and local environment files from the repository. Provide example environment files (such as `.env.example`) with placeholder values when configuration needs to be documented.
